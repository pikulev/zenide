# Changelog

Записываются только ЛОМАЮЩИЕ изменения контрактов (перечислены в
[docs/architecture.md](docs/architecture.md#контракты)) — то, из-за чего у
форкнувшего что-то перестанет работать. Остальное читается по git log.

## Следующая версия

- **Откат сохраняет изменённое.** Изменённые копии и подменённые пути
  перемещаются в `*.saved.*/value`; созданные личные файлы профиля остаются.
  Проверка `git diff ide/` больше не блокирует снятие симлинков. Новый журнал
  содержит отпечатки копий и записи `keep`: откатывать его нужно новым
  `install.sh`. Старые журналы читаются с сохранением неизвестных копий.
- **`--copy`: входная команда ссылается на установленную копию ядра.**
  Прямого копирования `bin/zenide` в `~/.local/bin` больше нет.
- **Окна yazi больше не пересоздаются по `E`.** Для уже работающего старого
  окна без `@zenide_yazi_id` один раз выйди через `q` и открой его заново.

## 0.1.0

Первая версия со слоями и диспетчером. Для тех, кто жил на структуре
`config/tmux/*.sh`, ломается почти всё:

- **Скрипты моста стали подкомандами.** `~/.config/tmux/hx-open.sh` →
  `zenide open`, и так для всех: `hx-ctx` → `ctx`, `hx-reload` → `reload`,
  `hx-go` → `goto`, `hx-files` → `files`, `hx-search` → `grep`, `hx-diff` →
  `diff`, `hx-blame` → `blame`, `sessionizer` → `project`, `git-status` →
  `status`, `keys.sh` → `keys`. Контекстные прыжки — `jump files` / `jump git`.
- **Инлайн-логика окон уехала из `tmux.conf`** в `zenide window git|files|search`.
- **Конфиги тулов переехали** из `config/<tool>/` в `ide/<tool>/`.
- **Раскладка стала двумя модулями** (`keyboard-force-latin`,
  `keyboard-cyrillic-twins`) и по умолчанию ВЫКЛЮЧЕНА. Включается в
  `profile/modules.conf`.
- **Появился слой `profile/`**: тема, корни проектов, личные бинды, слоты.
  Тема больше не в `tmux.conf`. `profile/*.local` под `.gitignore` — туда
  уходит identity и рабочее.
- **git identity вынесена** в `profile/git.local` через `[include]`.
- **`sh/` → `shell/`.** Требует правки `SHELL_CONFIG_ROOT` в `~/.zshrc`;
  `bootstrap.sh` переводит старую строку сам.
- **Установка разделена:** `install.sh` (симлинки и профиль, часть проекта) и
  `bootstrap.sh` (личное окружение, зовёт первый).
- **`Brewfile` теперь только ядро** (~13 формул), остальное в `Brewfile.full`.
- `nvim`, iTerm2 и alacritty уехали в `attic/`.
